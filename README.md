# My personal bash script directory
In this Github repo you can find a bunch of original bash scripts that I frequently use.

You might find this an interesting read if you are a beginner in some of these areas since it may be useful to get an example of an starting path.
Specially if you are a beginner with bash-scripting, it will be a nice excercise to try to reverse engineer these scripts to find out how do they work.

Anyways, here is the list of scripts:
- **backup.sh**. Lets you make quick archives of directories for storing purposes.
- **digitalize.sh**. Streamline my process for saving time when images multiple images in my University notes. 
- **duu.sh**. Small script, that uses the `du` command for obtaining the disk usage of files.
- **gstatus.sh**. Small script for obtaining updated info of all Git repos on a directory.
- **gstatus2.sh**. Same as the previous one, but improved.
- **opn.sh**. Short script that implements `fzz` to let you quickly open files with `nvim`.
- **scraper.sh**. Very small script for obtaining the source code of a page and applying some filters to only keep some of the information.
- **sort-class-notes.sh**. Quickly sort all my class notes.

On my machine, I have aliases for all of these scripts so that I can use them fast and very easily.
